Corporate Employee Support Portal

Project Description

The Corporate Employee Support Portal is a web application designed to provide employees with a platform for accessing support services and information.

Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

Project Features

- Employee support interface
- User-friendly design
- Responsive web application

How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run "npm install".
5. Run "npm run dev".
6. Open the local URL displayed in the terminal.
